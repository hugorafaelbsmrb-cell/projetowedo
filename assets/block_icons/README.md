# Ícones dos Blocos (PNG)

Este diretório contém os ícones usados nos blocos do WeDo 2.0.
Para alterar um ícone, basta substituir o arquivo PNG correspondente mantendo o mesmo nome, ou adicionar um novo arquivo e atualizar o `js/blocks/custom_blocks.js`.

## Arquivos Esperados:

- `play.png` - Bloco Iniciar
- `motor.png` - Bloco Motor (Genérico)
- `wait.png` - Bloco Esperar
- `loop.png` - Bloco Repetir
- `led.png` - Bloco LED
- `sound.png` - Bloco Som

## Especificações Recomendadas:

- **Formato:** PNG (fundo transparente)
- **Dimensões:** 64x64 pixels ou 128x128 pixels (serão redimensionados para 32x32 ou 24x24 no bloco)
- **Estilo:** Ícones brancos ou coloridos com bom contraste.
